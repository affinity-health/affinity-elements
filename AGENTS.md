# Affinity Elements

- Use Bun for installs and scripts.
- Use Vite+ for checks, tests, and package builds.
- Keep API keys out of browser code.
- Preserve the exact-origin iframe handshake and the single-use client-secret boundary.
- Use ASD-STE100 principles for customer documentation.
- Commit with `committer`, and list each intended file.
- Do not publish or push without explicit user authorization.
